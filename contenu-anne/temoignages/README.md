# Témoignages d'acheteurs non clients

Des personnes que tu as accompagnées **sans qu'elles achètent avec toi** — c'est précisément ce qui rend leur parole crédible. **3 minimum.**

Un fichier par personne, par exemple `marie-evian.md` :

```
Prénom :
Contexte :        (une ligne : situation, ce que tu as fait pour elle)
Citation :        (ses mots, 2 à 5 lignes)
Portrait :        (facultatif)
Autorisation :    (date et forme de son accord — un e-mail suffit)
```
