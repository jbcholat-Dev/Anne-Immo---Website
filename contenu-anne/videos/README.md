# Vidéos

Les vidéos sont **trop lourdes pour Git** : ne les dépose pas ici (elles sont ignorées automatiquement). Partage-les via un dossier OneDrive (ou WeTransfer) et **mets le lien dans `liens.md`**, une ligne par vidéo : nom, durée, ce qu'on y voit.

## Ce qu'il faut

- **Vidéo d'ouverture** : paysage 16:9, 10 à 20 secondes exploitables en boucle, sans incrustation ni logo, 1920 px de large minimum. Si possible un recadrage portrait ou carré pour le mobile.
- Toute autre séquence drone ou de bien : même règle, originaux non compressés.
